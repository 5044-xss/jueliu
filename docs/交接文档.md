## 1. 项目定位

本地运行的单人 AI 漫剧创作工作台（不部署服务器）。核心目标是把「一致性」和「连续性」在**提示词层面**做到极致：

```
项目 → 故事 → 剧本 → 资产 → 分镜(段/镜) → 平台提示词 → 外部生成 → 回传视频 → 截尾帧 → 合成
```

**能力边界**：本工作台只保证「提示词/约束/数据结构正确」，不保证第三方模型生成的画面结果。

**非目标**：不做视频生成、不做图片生成、不做云端部署、不做模型训练。

## 6. 核心设计决策（务必先读，避免改错方向）

### 6.1 输出 JSON 结构由「内置契约」强制，不可编辑
`src/lib/llm/structured.ts` 的 `buildOutputContract(schema)` 用 `z.toJSONSchema()` 生成 JSON Schema，**强制附加到 system 末尾**。用户提示词只描述内容/风格，不负责结构。解析失败自动重试（含关闭 JSON mode 的回退）。

> 已实测：把提示词换成完全不含 JSON 的极简描述，输出仍能正确解析。**不要**把 JSON 结构写回可编辑提示词里。

### 6.2 技能库 = 每类能力多个技能条目 + 选用
- 技能类型（kind）固定三种：`story-to-script` / `script-to-assets` / `script-to-storyboard`（`SKILL_KINDS`）。
- 每个 kind 下可建多个技能条目（不同提示词），用 `isDefault` 单选「使用中」。
- 生成时 `getActiveSkillPrompt(kind)` 读取当前条目；`prompt` 为空则回落到代码内置 `skill.systemPrompt`。
- 没有「启用/停用」开关（已按需求移除）。
- 技能定义在 `src/lib/skills/*`，注册于 `registry.ts`。

### 6.3 厂商模板：默认优先
- `DEFAULT_PLATFORM = "custom"`，标签「默认（通用）」，永远存在且是弹窗默认 Tab。
- 渲染 `POST /api/render/platform` 按 `platform` 取全局模板 `getTemplateByPlatform()`；未命中回落 custom。
- 弹窗 Tab 由模板库动态生成，顺序 custom 优先（`sortPlatforms`）。

### 6.4 图片清单（manifest）编号规则
顺序固定：`首帧(若有) → 场景 → 角色(按出场顺序) → 道具`；同一 `viewId` 复用同一编号；不同角度/变体不同编号。提示词统一用 `@图N` 引用。实现见 `src/lib/render.ts` 的 `buildManifest()`。

### 6.5 首帧锚定
段尾帧可「设为下一段首帧」→ 写入下一段 `segment.first_frame_id` → 渲染时成为该段图1，图例首行「图1=首帧（上一段尾帧）」。

### 6.6 连续性规则集
项目级 `continuity_rule_set.rules_json`，8 个布尔开关（axis180/eyelineMatch/lightingContinuity/focalLogic/wardrobeProp/blockingLock/actionMatch/firstFrameAnchor）。校验器 `src/lib/continuity.ts` 输出 warning/info，在分镜页展示，不阻塞。

### 6.7 全局库 vs 项目级
风格/模板/技能是**全局可复用**（`workspace/library/`）；剧本/资产/分镜/视频是**项目级**（project.db）。风格在项目上存 `style_id` + 解析后的 `style` 文本快照。

`C:\Users\ADMINI~1\AppData\Local\Temp\opencode\`。示例骨架：

```js
const BASE = "http://localhost:3210";
async function req(method, path, body) {
  const res = await fetch(BASE + path, {
    method,
    headers: body ? { "Content-Type": "application/json" } : undefined,
    body: body ? JSON.stringify(body) : undefined,
  });
  return { status: res.status, data: await res.json().catch(() => null) };
}
// 上传视频：
const fd = new FormData();
fd.append("file", new Blob([buf], { type: "video/mp4" }), "clip.mp4");
await fetch(`${BASE}/api/projects/${id}/segments/${seg}/video`, { method: "POST", body: fd });
```

   - 改剧本 → 资产/分镜/视频/合成失效
   - 改资产 → 分镜(引用)/视频/合成失效
   - 改分镜 → 视频/合成失效
3. 在 `saveStory`、`saveScript`、`saveAssetDrafts`、`saveStoryboard` 等写入点调用 `markDownstreamStale()`。
4. 前端：进入下游页时若 stale，弹二次确认，确认后清空并解除标记。
5. 打磨项：空状态、错误提示、加载态、生成弹窗的清单顺序提示、连续性 warning 的可跳转定位。
